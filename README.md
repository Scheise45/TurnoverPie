# TurnoverPie

**TurnoverPie** — настольное приложение для автоматизации учета поступающих товарно-материальных ценностей (ТМЦ) в сети ресторанов.

Проект разрабатывается в рамках прикладной задачи и предназначен для упрощения взаимодействия торговых подразделений и ревизорской службы при ведении журнала учета накладных.

## Основные возможности

### Версия кассира

- Пошаговое заполнение накладной в виде цепочки вопросов.
- Выбор ответов из справочников.
- Автоматическое формирование строки журнала учета накладных.
- Сохранение данных в Excel.
- Автоматическое получение обновлений справочников.

### Версия ревизора

- Управление справочниками (поставщики, вопросы и др.).
- Публикация обновлений для рабочих мест кассиров.
- Просмотр и анализ сформированных журналов.

## Архитектура

Проект состоит из двух независимых приложений:

- **Cashier** — рабочее место кассира.
- **Auditor** — рабочее место ревизора.

Обмен данными осуществляется через общее облачное хранилище без использования собственного сервера.
